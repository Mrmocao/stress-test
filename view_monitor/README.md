# 独立播放量监控

用于定时查询指定哔哩哔哩视频的公开播放量，并记录基线、最新值、增量和每次观测结果。此模块只依赖 Python 标准库，不依赖原来的 TV 播放程序、签名模块、FFmpeg 或 Python 第三方包。

## 打开与启动

双击本目录的 `启动播放量监控.cmd`，然后访问：

**http://127.0.0.1:8766/**

也可以在本目录运行：

```powershell
python monitor.py
```

Windows 后台启动脚本优先复用上级项目现有 `.venv`；复制整个 `view_monitor` 文件夹到其他地方后，可以直接用已安装的 Python 3.11+ 运行，不需要 pip 安装依赖。

页面输入视频地址或 BV/av 号后点击「开始观测」。默认每 30 秒查询一次，持续 60 分钟，到时自动停止，也可手动停止。关闭页面不会停止后台观测；退出服务或关闭电脑会中断采集。

本次基础测试视频：`BV1S64q69EPN`。输入以下完整地址也可以：

```text
https://www.bilibili.com/video/BV1S64q69EPN/?spm_id_from=333.337.search-card.all.click
```

支持 `BV` + 10 位字母数字、`av` + 数字、纯数字 AID、bilibili.com 的 `/video/…` 链接。b23.tv 短链接请先用浏览器打开，取得最终视频地址。

如需命令行启动服务时立即开始监控：

```powershell
python monitor.py --video BV1S64q69EPN --interval 30 --minutes 60
```

可用 `--port 8767` 更换端口，`--data-dir <目录>` 更换记录目录。同一个记录目录只允许一个服务进程持有文件锁，避免不同服务相互修改观测状态。

## 数据源与边界

唯一的对外网络操作为：

```text
GET https://api.bilibili.com/x/web-interface/view?bvid=<视频ID>&_monitor_time=<时间参数>
```

使用响应中的 `data.stat.view`，同时保存公开的其他统计字段和视频标题、UP 主等信息。AID 输入使用同一接口的 aid 参数。

模块不会访问视频页面、获取播放地址、下载视频/音频资源，也不会发送 heartbeat、click 等播放上报。观测查询与原播放程序互不依赖。

每次请求附加时间参数和 no-cache 请求头，以减少复用同一个 HTTP 响应的机会，但不能绕过平台内部的统计更新延迟或缓存。保存响应的 Date、Age、Cache-Control、X-Cache（服务端存在时），便于排查。

公开播放量增加仅说明观察到了公开数值增加；无法单独证明某次播放被计入。未变化也仅描述已观察到的时间窗口，不代表后续永远不会更新。

## 指标定义

| 指标 | 定义 |
| --- | --- |
| 基线播放量 | 当前这轮观测中第一次成功查询的 `stat.view` |
| 最新公开播放量 | 最近一次成功查询的 `stat.view`；并显示其采集时间 |
| 相对基线变化 | 最新播放量减去基线 |
| 较上次成功查询 | 本次播放量减去上一条成功查询值；错误样本不参与计算 |
| 成功观测次数 | 取得合法视频身份与非负整数播放量的次数 |
| 首次增加时间 | 第一次观测到播放量高于基线的时间，不是平台实际增加的精确时刻 |
| 数值下降 | 原样保留负差值，可能来自统计修正或缓存差异，不强行归零 |

只有一条成功记录时，页面不会宣称“播放量没有变化”，而会提示至少需要两次成功查询。失败样本显示空播放量与具体错误，并保留之前的有效基线、最新数值和数据年龄。

## 查询调度和停止

- 查询间隔可设为 15～3600 秒，观测时长可设为 1～1440 分钟。
- 首次查询立即开始；随后在每次响应返回后等待所设间隔，所以开始时间间隔还包含网络请求耗时。
- 单次远程请求超时为 20 秒。失败会退避：例如 30 秒配置下，连续失败分别等 60、120、240、300 秒；成功后恢复常规间隔。较长的用户间隔不会被缩短。
- 点击停止后，不再启动下一次查询；若已有请求进行中，等待它返回或超时后结束，因此状态可能短暂显示「正在停止」。
- 服务重启保留历史数据，不会自动恢复外部查询。先前未正常结束的观测标记为 interrupted。
- 一次只观测一个视频。停止后可以换视频开启新一轮，旧记录在历史选择框中保留。

## 导出与文件

每轮观测记录在本目录的 `data/YYYYMMDD-HHMMSS-随机片段/`：

```text
session.json           基线、当前值、增量、状态、调度参数和统计摘要
samples.jsonl          每次成功/失败观测，包含时间、变化值、延迟和错误
samples.csv            适合 Excel 打开的 UTF-8 BOM 表格
responses/0001.json    对应成功查询的原始 API JSON；错误查询不会伪造响应
```

网页的「导出 CSV」「JSON」可下载当前所选历史观测的全部记录。网页列表最多显示最近 500 条，历史选择框展示最近 50 轮；磁盘保留完整文件。

后台服务日志在 `data/server.stdout.log`、`data/server.stderr.log`，PID 在 `data/server.pid`。确认该 PID 仍属于本服务后可以停止它。前台运行时按 Ctrl+C，会先停止观测再关闭服务。

## 检查

本目录运行：

```powershell
python -m unittest -v test_monitor
```

测试覆盖有效输入、身份核对、基线建立、失败样本隔离、增量计算、数值下降、零播放量、参数约束、停止/历史恢复以及快照隔离。测试中的远程查询使用本地模拟，不会播放任何视频。

服务仅监听 127.0.0.1；修改类请求使用页面会话令牌和同源检查。它适合作为本机观测工具，没有多用户访问管理。
